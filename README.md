# 阅读器

极简瑞士风的 PDF 阅读器（macOS / Windows）：左侧 Markdown 笔记，中间 PDF，右侧可以并排显示译文。扫描版可以在线 OCR，论文和书可以解析版面、逐段翻译，并导出带文字层的 PDF 或 .md。

![阅读页：左侧笔记，中间 PDF，右侧译文；点一段译文，PDF 上用红框标出原文](docs/screenshots/reader-translation.png)

| 图书馆：鼠标移到一行上展开各项功能 | 扫描版的书：OCR 文字层上的划线、高亮和图章，左侧是笔记 |
|---|---|
| ![图书馆](docs/screenshots/library.png) | ![笔记与批注](docs/screenshots/reader-notes.png) |

技术栈：Electron + React + Vite + TypeScript，PDF 渲染用 pdf.js，Markdown 用 react-markdown + GFM。

应用图标源文件在 `build/icon.svg`，其他备选方案在 `build/icon-options/`。

## 下载安装

在 [Releases](https://github.com/TerraRiver/personal_reader/releases) 页面下载最新版本：

- **macOS**（Apple 芯片）：`Reader-x.y.z-arm64.dmg`
- **Windows**（64 位）：`Reader Setup x.y.z.exe`

安装包没有签名。mac 第一次打开会被拦下，到「系统设置 → 隐私与安全性」点「仍要打开」；Windows 会弹出 SmartScreen，点「更多信息」→「仍要运行」。

## 开发

```bash
npm install
npm run dev       # 开发模式（Vite 热更新 + Electron）
npm run dist      # 打包为 .dmg（Apple Silicon），输出到 release/
npm run dist:win  # 打包为 Windows 安装程序 .exe（x64），输出到 release/
```

在 Apple 芯片的 Mac 上打 Windows 包需要先装 Rosetta（`softwareupdate --install-rosetta --agree-to-license`），因为 electron-builder 自带的 makensis 是 x86_64 程序。exe 未签名，首次运行时 SmartScreen 会提示，选「仍要运行」即可。

## 发布

GitHub Actions 会在云端同时打出 mac 和 Windows 两个安装包（`.github/workflows/release.yml`）：

1. 改 `package.json` 里的版本号（如 `npm version 0.6.0 --no-git-tag-version`），提交。
2. 打同名标签并推送：`git tag v0.6.0 && git push origin main v0.6.0`。标签必须和版本号一致，否则构建会直接报错。
3. 大约十分钟后，仓库的 Releases 页面出现一个**草稿**，附带 `Reader-0.6.0-arm64.dmg` 和 `Reader Setup 0.6.0.exe`。检查无误后点「Publish release」才会公开。

只想试打包、不发布时，在 Actions 页面选「Release」→「Run workflow」，安装包会作为这次运行的附件保存，不生成 Release。

安装包没有签名，安装时的提示见上面「下载安装」。

## 图书馆与分类

- 所有 PDF 都在首页「图书馆」一个列表里，书和论文的阅读、笔记、书签、批注、OCR、解析、翻译完全相同。
- 每行显示书名、页数、书签数、阅读进度和上次阅读时间；鼠标移上去会展开第二行，是 OCR、解析、翻译的状态和按钮，以及「导出」「重命名」「移除」。正在处理或失败的行会一直展开。
- 左侧是**分类**：「全部」、自建的分类，以及有内容时才出现的「未分类」。点「分类」旁边的「+」新建；鼠标停在分类上，左边的「⊖」删除（点两次才删，删除分类不会删除 PDF，其中的 PDF 回到「未分类」），右边的毛笔图标重命名。
- 把一行拖到左侧某个分类上即可归类；也可以把 PDF 文件直接拖到某个分类上导入。选中某个分类时点「导入 PDF」或拖进窗口，新 PDF 直接放进这个分类。
- 从阅读器返回（「← 图书馆」）时回到打开前所在的分类。
- 从旧版本升级时，原来「书库」里的书自动放进「书籍」分类，「论文库」里的论文保留原来的分类。

## EPUB

- 「导入 PDF」和拖进窗口都可以导入 `.epub`。导入时把 EPUB 排成一份 **A5 大小的 PDF**，之后和其他 PDF 完全一样：笔记、批注、书签、进度、解析、翻译都按这份 PDF 的页码。
- 每一章从新的一页开始。EPUB 的目录自动变成书签；链接到章节中间的目录项，按同名标题找到所在的页。
- EPUB 没有纸书页码，「插入引注」直接用 PDF 页码，不用再填正文起始页。
- 原 EPUB 一起保存（`books/<id>.epub`），排版只在导入时做一次。书里的脚本不会运行，也不会加载网络上的图片或字体。
- 有 DRM 加密的 EPUB 无法导入，会提示原因。

## OCR、解析、翻译

对 PDF 的处理分三步，互相独立，列表里「文字」「结构」「译文」三栏分别显示：

| 步骤 | 服务 | 作用 | 可以导出 |
|---|---|---|---|
| OCR | 飞桨 PP-OCRv6 | 扫描页上的文字可以选中、复制、搜索 | 带文字层的 PDF |
| 解析 | MinerU | 识别标题、段落、注释、参考文献、表格、公式、图片 | .md（和图片一起打包成 .zip） |
| 翻译 | 大模型 | 逐段译成中文，和原文 PDF 并排对照 | — |

OCR 和解析互不依赖（MinerU 自己会识别扫描页）；翻译用的是解析出的段落，所以**翻译前需要先解析**。

## 解析与翻译

- **配置**：图书馆右上方「设置」→「解析与翻译」。填写 MinerU 的 API 密钥（解析版面），以及一个兼容 OpenAI Chat Completions 的翻译模型（接口地址、模型名称、密钥、并发数）。两组都可以「测试连接」，测试不消耗额度。密钥用系统钥匙串加密保存。
- **解析**：「结构」一栏点「解析」，进度按页显示（解析中 230/412 页）；也可以在阅读器的译文栏里点「解析」。超过 50 页会先提示要用掉的 MinerU 额度。超过 200 页的 PDF 按 100 页一块拆开解析，再按页码拼接起来，跨块的段落会接上。中途退出应用，下次打开从中断处继续；某一块失败时点「重试」只重新提交这一块。
- **解析做了什么**：MinerU 识别正文、标题、脚注、参考文献、图表；应用会合并被分页截断的段落，跳过页眉页脚和数据库封面页，纠正被误判的注释与参考文献。
- **导出 .md**：解析完成后，行末「导出」→「.md」，保存为一个 .zip，里面是 .md 和用到的图片。旧版本解析的结果没有保存图片，导出前需要重新解析一次；已有的译文和修改会按原文对应到新的解析结果上。
- **翻译**：「译文」一栏点「翻译」。50 页以内整篇翻译；超过 50 页时先选页码范围，默认是还没翻译的下 50 页，并显示大约多少段、多少字。已经译过的段落不会重复翻译，跨页的段落按开头所在的页算。列表里显示「已译 100/380 页」，点「继续」翻译下一段；阅读器译文栏里没翻译的页显示为「第 101–380 页未翻译」，点「翻译这部分」也可以继续。
- **流程**：第一次翻译前先让模型通读全文开头生成术语表，之后翻译其他页码范围都沿用同一份，保证全书译法统一。参考文献保留原文；注释只译说明文字，书目信息保留原文。
- **对照阅读**：译文显示在 PDF 右侧，和原文并排，左栏笔记不受影响。有译文的书打开时自动显示译文栏，右上角的「隐藏译文 / 显示译文」收起或展开译文栏（和「隐藏笔记」并排）。三栏都打开时各占三分之一，两栏时各占一半。点一段译文，PDF 翻到对应位置并用红框标出原文；开启「跟随翻页」时，翻 PDF 译文也跟着走。「原文」开关在每段译文下显示原文。
- **修改译文**：鼠标停在段落上点「编辑」（或双击段落），上方显示原文，下面直接改；⌘Enter 保存，Esc 取消。译文是 Markdown，脚注序号写作 `^12^`，公式写作 `$…$`。改过的段落标为「已修改」，可以「恢复机器译文」；「重译」让模型重新翻译这一段（会替换掉修改）。
- MinerU 每个账号每天 1,000 页高优先级额度。解析和翻译时，PDF 内容会发送给 MinerU 和你配置的模型服务商。
- 开发时也可以在 `.env` 里配置：`MinerU_Key`、`MinerU_Model_Name`、`LLM_Base_URL`、`LLM_Model_Name`、`LLM_Api_Key`；设置里保存的值优先。

## 笔记怎么用

- 两个按钮：「开始笔记」和「截断」。
- 读到想记笔记的地方点「开始笔记」，笔记从当前页开始；觉得内容进入下一部分时点「截断」，笔记在当前页结束。截断只负责结束，不会自动开新笔记，不想记的部分可以空着。
- 「开始笔记」只能在没有笔记的页，或上一篇的截断页使用（章节不从新的一页开始时，两篇笔记共用这一页，编辑器上方可切换）。
- 页码范围写在笔记源码开头，直接修改即可微调（`12-` 表示尚未截断）：

  ```
  ---
  页码: 12-18
  ---
  ```

- 开启「跟随翻页」时，PDF 和笔记互相跟随：翻 PDF 会显示当前页对应的笔记，从笔记列表选笔记时 PDF 翻到它的页码。关闭后两边互不跟随（笔记里的页码链接和引注仍可点击跳转）。
- **自由写**：「笔记列表」「废纸篓」右边的「自由写」打开这本书的自由笔记，整本书一篇，不和页码绑定，翻页时保持打开。同样支持 Markdown、预览和插入引注；写过内容后按钮旁有小红点。
- 删除的笔记进入废纸篓，可恢复。笔记里写 `[第 12 页](#p12)` 可生成跳转链接。
- **插入引注**：编辑笔记时点「截断」右边的「插入引注」，在光标处插入 `[p 12]`，12 是书上印的页码（不是 PDF 页码）。每本书第一次使用时要填「正文第 1 页是 PDF 第几页」，之后自动换算；右侧的「第 19 页 · 书上 p15」显示当前页对应的书页，点它可修改正文起始页。正文之前的序言、书评等页会插入 `[p x]` 并选中 x，直接输入页码即可（提示可按书关闭）。预览模式下，`[p 12]` 可点击，跳到对应的 PDF 页；从笔记里跳转时笔记保持显示，手动翻页后再恢复跟随。

## 书签与文字层

- 导入后自动检测每本书的文字状态（原生文字 / 已 OCR / 未 OCR，鼠标移到列表行上可见）和书签数量。
- 阅读器中点「书签」（⌘B / Ctrl+B）打开书签栏：点击跳转，可添加、重命名、改页码、调整层级、删除或清空。
- 首次打开时导入 PDF 自带书签；之后的编辑保存在应用里，不改动 PDF 文件。

## 批注

原生文字页和 OCR 识别过的扫描页都可以批注，批注单独保存，不改动 PDF 文件。

- **选中文字**：松开鼠标自动复制（可在「设置」里关闭），旁边弹出工具条：选颜色（黄 / 绿 / 蓝 / 粉 / 红），再点「高亮」「横线」或「波浪线」。点已有的批注可以改颜色、改样式、复制原文或删除。
- **图章**：在 PDF 页面上**右键**，就地弹出图章菜单（可选颜色），点一个图章就盖在右键的位置。要连续盖同一种图章时，点工具栏「图章」打开面板，选一个后逐个点击页面，Esc 或关闭面板结束。共 8 种：对号、错号、圆圈 / 方框 / 实心三种序号、问号、感叹号、星号。
- 图章面板顶部可选颜色（与文字批注同一组）；盖好的图章选中后，下方的色块可改颜色。
- 盖好的图章可以拖动，选中后拖四角缩放，按 Delete 删除。
- 批注和图章的每一步都可以 ⌘Z 撤销、⌘⇧Z 重做（Windows 为 Ctrl+Z / Ctrl+Y），撤销其他页的改动会自动翻过去。光标在笔记编辑区时，⌘Z 撤销的是文字。
- **序号**：每种样式在整本书里连续编号，面板上可以用 − / + 调下一个号，或「序号从 1 开始」重新编号。选中序号后直接按数字键改号码（连按组成多位数），改的是最新一个时，后面的序号跟着接上。

## OCR（飞桨 PP-OCRv6）

扫描版的书（文字一栏显示「未 OCR」）可以点旁边的「OCR」，交给飞桨 AI Studio 的 PP-OCRv6 在线识别。识别结果单独保存，不改动 PDF 文件；之后扫描页上的文字可以像电子版一样选中、复制。

- 需要飞桨 AI Studio 的访问令牌：图书馆右上方「设置」里有获取步骤，粘贴后会先验证（不消耗额度）再用系统钥匙串加密保存在本机。没有令牌时点「OCR」会直接打开设置。
- 开发时也可以把令牌写在项目根目录的 `.env`（`Access_Token = 你的令牌`，已加入 `.gitignore`）或环境变量 `PADDLEOCR_ACCESS_TOKEN`；设置里保存的令牌优先。
- 每个模型每天 20,000 页额度。书按每 30 页一份上传（几份同时识别），每完成一份，阅读器里对应的页面就能选中文字，不用等整本完成；识别期间照常阅读即可。
- 识别中退出应用，下次打开会从中断处继续；失败时把鼠标停在「OCR 失败」上可以看到原因，点「重试」从中断处继续。
- 识别时会自动纠正 90° / 180° / 270° 旋转的页面。
- **导出带文字层的 PDF**：在这里完成 OCR 的书，行末「导出」→「PDF」，另存一份带不可见文字层的 PDF，在预览、Acrobat、浏览器等其他阅读器里也能选中、复制、搜索扫描页上的文字。原 PDF 不改动，页面外观不变；全程在本地完成，不花额度。

## 快捷键

Windows 上把 ⌘ 换成 Ctrl。

| 按键 | 作用 |
|---|---|
| ← → / 空格 / PageUp PageDown | 翻页（触控板左右或上下滑动也可以） |
| Home / End | 第一页 / 最后一页 |
| ⌘Z / ⌘⇧Z | 撤销 / 重做（批注；编辑笔记时为文字） |
| ⌘E | 切换源码 / 预览 |
| ⌘\ | 显示 / 隐藏笔记栏 |
| ⌘B | 显示 / 隐藏书签栏 |
| 双指捏合 | 缩放 PDF |

## 数据位置

- macOS：`~/Library/Application Support/Reader/library/`
- Windows：`%APPDATA%\Reader\library\`

目录内容：

- `library.json` — 书目、页数、阅读进度、分类
- `books/<id>.pdf` — 导入时复制进来的 PDF（EPUB 则是排好的 A5 PDF）
- `books/<id>.epub` — 导入的 EPUB 原文件
- `notes/<id>.json` — 该书的笔记与废纸篓
- `bookmarks/<id>.json` — 该书的书签
- `ocr/<id>.json` — 该书的 OCR 结果（每行文字及其在页面上的位置）
- `annotations/<id>.json` — 该书的高亮、划线和图章
- `parsed/<id>/` — 该书的解析结果：`state.json`（各块进度和清理后的段落）、`chunk-<起始页>.json`（每块的 MinerU 内容列表）、`images/`
- `translations/<id>.json` — 该书的译文（含你修改过的段落）、术语表和已翻译的页码范围

访问令牌和解析、翻译用的密钥不在 `library/` 目录里，而是加密保存在上一级的 `settings.json`。

开发调试可用环境变量 `READER_DATA_DIR` 指向一个临时数据目录，`READER_PROD=1` 让未打包的应用加载 `dist/` 构建产物。
